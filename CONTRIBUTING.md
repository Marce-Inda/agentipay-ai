# Contributing to AgenticPay AI 🤝

Thank you for participating in the development of **AgenticPay AI**!

---

## 🛠️ Development Guidelines

1. **Code Conventions:**
   * TypeScript strict mode enabled.
   * Format code using Prettier (`npm run format`).
   * Lint using ESLint (`npm run lint`).

2. **Commit Message Standard:**
   Use Conventional Commits format:
   * `feat: add Agent-to-Agent negotiation protocol`
   * `fix: handle PayPal Sandbox OAuth token expiration`
   * `docs: update ARCHITECTURE.md diagram`

3. **Testing PayPal Integrations:**
   * Always use Sandbox test accounts created in [developer.paypal.com](https://developer.paypal.com).
   * Never commit real production API credentials.
